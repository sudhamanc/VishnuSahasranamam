Drop your legally obtained M. S. Subbulakshmi recitation here as:

    recitation.mp3

The app looks for this file on the deployed site and plays it in Learn and Listen.

Do not commit the MP3 to GitHub. It stays gitignored. To put it on Netlify, either:

- copy the file here, then deploy the folder with the Netlify CLI or Netlify Drop, or
- set `RECITATION_URL` in the Netlify site settings to a direct link you control.
